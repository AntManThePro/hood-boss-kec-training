## How techs use it

1. Open the first dropdown — **LEVEL 1 / New Technician**. Leave it there.
2. Open the second dropdown and run modules in order.
3. Tap a section title to drop the checkboxes. Check what you can do.
4. Quiz needs 80%. Sign-off lives on that phone only.
5. Do not open Audience unless you are the manager.

Operating rule: **Stop. Protect. Document. Escalate.**

## Audience

- Technician (default): Academy, Playbook, MyTechPix Guide, Q10, Safety, FieldPulse, NFPA 96, OSHA
- Manager (code-gated): Team Lead OS / Path / Briefing, QA Brain, Cycle Gate, Follow-up OS, Scorecard, Recruiting Hub, KEC SHIELD (TWC)

This is training guidance, not a substitute for current company SOPs, SDS, equipment manuals, adopted code, or AHJ direction.
